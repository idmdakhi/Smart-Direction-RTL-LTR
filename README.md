# Smart Direction — تشخیص هوشمند RTL/LTR

افزونه‌ی کروم (Manifest V3) که جهت متن هر بخش از صفحه را بر اساس محتوای واقعی آن تشخیص می‌دهد: فارسی/عربی/عبری → راست‌به‌چپ، انگلیسی/لاتین → چپ‌به‌راست، و **کدهای برنامه‌نویسی همیشه چپ‌به‌راست** — حتی اگر داخل یک صفحه‌ی کاملاً فارسی باشند.

## 📥 نصب

### از فروشگاه کروم (به زودی)

1. به [فروشگاه کروم](https://chrome.google.com/webstore) بروید.
2. افزونه‌ی Smart Direction را جستجو و نصب کنید.

### حالت توسعه‌دهنده

1. این پوشه را کلون کنید یا دانلود نمایید.
2. در کروم به آدرس `chrome://extensions` بروید.
3. **حالت توسعه‌دهنده** را فعال کنید.
4. روی **Load unpacked** بزنید و پوشه‌ی پروژه را انتخاب کنید.
5. آیکون را پین کنید تا بَدج را ببینید.

## 🚀 استفاده

### پاپ‌آپ

روی آیکون کلیک کنید تا پاپ‌آپ باز شود:

- **حالت**: خودکار / همیشه LTR / همیشه RTL / خاموش
- **آستانه**: درصد حروف RTL مورد نیاز برای تشخیص (پیش‌فرض ۴۰٪)
- **پیش‌فرض برای همه‌ی سایت‌ها**: با تیک زدن، تنظیم سراسری می‌شود.
- **حذف تنظیم اختصاصی**: override محلی را پاک می‌کند.
- **اعمال روی همه‌ی تب‌ها**: تنظیمات فعلی را به همه‌ی تب‌های باز اعمال می‌کند.
- **بازنشانی به پیش‌فرض**: تمام تنظیمات را به حالت اولیه برمی‌گرداند.

### کلیک روی آیکون

با هر بار کلیک روی آیکون افزونه، حالت به‌صورت چرخشی تغییر می‌کند:  
**خودکار → LTR → RTL → خاموش → خودکار → ...**

### میانبرهای صفحه‌کلید

| میانبر         | عملکرد      |
| -------------- | ----------- |
| `Ctrl+Shift+A` | حالت خودکار |
| `Ctrl+Shift+L` | حالت LTR    |
| `Ctrl+Shift+R` | حالت RTL    |
| `Ctrl+Shift+O` | خاموش       |

> **نکته:** می‌توانید میانبرهای دلخواه را در `chrome://extensions/shortcuts` تنظیم کنید.

### تنظیمات پیشرفته

از طریق پاپ‌آپ یا کلیک راست روی آیکون → «گزینه‌ها» وارد صفحه‌ی تنظیمات شوید:

- **پیش‌فرض سراسری**: تنظیمات پیش‌فرض برای همه‌ی سایت‌ها
- **تشخیص خودکار زبان**: در حالت خودکار، زبان صفحه را تشخیص داده و جهت مناسب را انتخاب می‌کند.
- **لیست سفید**: سایت‌هایی که همیشه پردازش می‌شوند (اگر خالی باشد، همه‌ی سایت‌ها پردازش می‌شوند).
- **لیست سیاه**: سایت‌هایی که هرگز پردازش نمی‌شوند.
- **مدیریت تنظیمات اختصاصی**: مشاهده و حذف overrideهای سایت‌ها
- **پشتیبان‌گیری و بازیابی**: ذخیره‌سازی تنظیمات به‌صورت فایل JSON و بازیابی در دستگاه دیگر.
- **آمار استفاده**: مشاهده‌ی تعداد سایت‌ها، بلوک‌های پردازش‌شده و توزیع حالت‌ها.
